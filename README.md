# Reinforcement Learning Fundamentals (Python)

This repository is a personal learning project focused on understanding the core concepts of Reinforcement Learning (RL) using the Python ecosystem.

The goal is to build a strong practical and theoretical foundation by experimenting with classic environments, starting from simple agents and progressively moving toward more advanced deep reinforcement learning techniques.

---

## 🎯 Purpose

The main objectives of this project are:

- Understand the fundamentals of Reinforcement Learning
- Learn how environments interact with agents using the Gymnasium API
- Explore how observations, actions, and rewards define an RL problem
- Implement basic preprocessing pipelines for visual environments (Atari-style inputs)
- Build intuition for policies, value functions, and learning dynamics

---

## 🧠 Key Topics Covered

- Markov Decision Processes (MDPs)
- Policy-based methods (e.g., REINFORCE)
- Value-based methods (e.g., Q-learning, DQN)
- Observation preprocessing (grayscale, resizing, frame stacking)
- Frame differencing and temporal representation
- Interaction with Atari environments via ALE

---

## 🛠️ Tech Stack

- Python
- Gymnasium
- ALE-py (Atari Learning Environment)
- NumPy
- Matplotlib
- PyTorch (planned for future models)

---

## 🎮 Environments

The project initially focuses on classic Environments such as:

- Blackjack
- Pong


These environments provide a simple yet powerful setting for studying sequential decision-making and learning from visual input.
